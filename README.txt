目前内容包括主页展示（包含粤气爱标题与简介）；追风记录栏目，左侧栏目可以查看我们历史追击的台风列表，右侧是众多我主要历史追风栏目，可点击查看这次追风的详情时间，人物，地点，强度以及一些感想/追风经历。此外我们还提供了数据源栏目，点击数据源，可以看到我日常使用众多气象网站的导航栏目，点击直接进入相应网页方便获取数据（如Windy zoomearth 东风波 中国追风者等）。右边点击粤气爱可以选择B站，抖音，小红书，微博等直接跳转到我们帐号各个平台的主页。

在网站顶端点击天气地图栏目选择“天气地图”就可以进入我们自主开发的天气地图。可以选择展示内容：点击“预警”展示全国主要城市和关注城市当前生效的预警信息分布，点击预警信息图标可以查看预警信息详情内容；而点击天气预报选项可以在地图上查看全国主要城市的日最低最高气温和当前天气，点击城市弹出详情资料卡可以展示更多气象要素：气压，温度，湿度，风速风向，降水量和能见度实况，往下拉就是未来七日的六要素最低最高温度，湿度，气压，日降水量，风速风向，能见度，空气质量的预报，最后还有一个依据未来七天各要素预测绘制的折线图，清晰看出未来各要素的变化趋势。再点击预警，资料卡顶端还会显示当前生效的预警信息与详细内容，可地图查询天气和预警信息的全国城市目前共有49个。除此之外，点击台风路径还可以查询最新台风位置以及风圈大小还有该台风历史路径以及官方对该台风的未来路径与强度预测（可选择，按点位连接可点击查看强度和时效且用不同颜色区分）；点击台风图标还可以查看当前台风名称，最新位置，风力，风速，中心气压，移动速度和方向。另外，你也可以点击我要预报自己来预报台风，预报该台风未来6，12，18，24，48，72，96小时时段并输入强度，点击确认预报位置。
点击天气地图另外一个“线上天气地图”栏目进入页面展示三个窗口，第一个窗口是个导航指引，用于查看卫星云图，点击交互式静轨卫星进入zoom earth，点击全圆盘卫星云图进入风云四号B星官方实时全圆盘；而云图窗口下面是Ventusky气象网站页面展示，是Windy在国内无法使用后的最佳替代品，包含不同要素非常多种气象要素的未来预测，并用地图可视化。
